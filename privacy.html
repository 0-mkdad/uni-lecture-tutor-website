Last updated 25 November 2026

Controller and contact

Mohammad Almekdad, an independent developer in Germany, is responsible for the project processing described here. For privacy questions or requests, email info@mkdad.de.

Website hosting

GitHub Pages delivers the site and logs visitor IP addresses for security. HTTP requests can also expose browser headers, timestamps and requested paths. The site loads its assets locally and its code uses no analytics, cookies or browser storage. The publisher relies on its legitimate interest in secure and reliable delivery (GDPR Article 6(1)(f)). GitHub describes its own processing and retention criteria.

Lectures and ChatGPT

ChatGPT processes lecture files, prompts and study conversations and generates explanations. The applicable OpenAI policy, account controls and workspace arrangements govern how OpenAI handles this data. Use OpenAI’s privacy policy and privacy portal for platform data and rights requests. The project website has no file upload feature.

Optional coverage calculator

When ChatGPT invokes validate_lecture_coverage, the Cloudflare Worker receives total_pages (the PDF page count) and covered_pages (the page numbers marked covered). It counts distinct covered pages and returns the remaining count, percentage and first uncovered page, if any. The tool is read-only and stateless. Its contract requires no files, text, filenames or student identity. The publisher maintains no separate student account or progress database.

Request metadata and retention

Cloudflare hosts the endpoint for the publisher. It may process HTTP metadata such as the connecting system’s IP address, request headers, timestamps, paths, response status and infrastructure logs. The publisher relies on its legitimate interest in providing the calculator and operating it securely (Article 6(1)(f)). The calculation is performed for the request. The production Worker currently has Workers Logs and Traces disabled. Cloudflare may still process technical data at the infrastructure level. Retention of technical data depends on the logging settings, the provider and the purpose, such as diagnosing errors or protecting the service. See Cloudflare and Workers Logs.

See the policies linked above and the Cloudflare DPA for details or contact the publisher to ask about applicable safeguards.
