# Security and privacy reporting

Please report suspected security vulnerabilities or privacy issues privately to **info@mkdad.de**. Include a short description, affected page or component, expected and actual behaviour, and non-sensitive steps to reproduce. Do not send passwords, tokens, private chat links, lecture contents or identifying student data. Use synthetic or redacted examples.

Do not publish an unresolved vulnerability or personal information in public issues. Test only systems you own or are authorised to assess; do not disrupt services or access other users’ data.

This repository contains the public static website. ChatGPT platform issues belong with [OpenAI support](https://help.openai.com/). The [privacy notice](https://0-mkdad.github.io/uni-lecture-tutor-website/privacy.html) explains the distinct data-processing boundaries.
